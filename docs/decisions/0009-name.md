# Decision

**JsonCall**, a pun on Jason and JSON-RPC (JavaScript Object Notation Remote Procedure *Call*).

| Thing | Name |
| --- | --- |
| Packages and namespaces | `JsonCall.*` |
| Command line tool | `jsoncall` (package `JsonCall.Tool`) |
| OpenRPC extensions | `x-jsoncall-` |
| Generator diagnostics | `JSONCALL` |

# Context

- `Jason` and `Jason.*` are taken on NuGet by an unrelated CQRS framework.
- `JsonCall`, `JsonCall.Core`, `JsonCall.Client` and `JsonCall.AspNetCore` were unclaimed on 2026-11-11. The
  `JsonCall.` prefix should be reserved on first publish.
- Rejected: CallJason, JaySong, JsonCalls, JsonCalling, Colchis, Iolcus, Aeaea, Medea, Pelias, JasonRpc.
